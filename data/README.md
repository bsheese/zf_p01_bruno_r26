# Data

## Source files (`data/source/`, read-only)

| File | Contents |
|------|----------|
| `tracking_triallevel_distortion_corrected.csv` | Frame-by-frame distortion-corrected fish positions (4,850,062 rows, ~153 MB). **Not stored in git** — download with `python data/source/get_raw_data.py`, which fetches it from Zenodo ([10.5281/zenodo.20707066](https://doi.org/10.5281/zenodo.20707066), CC BY 4.0) and verifies its SHA-256 checksum. |
| `tracking_aggregate_uncorrected.csv` | Per-session summary from the original analysis. Its `include` column carries the original QC flags (`include = 0` → 35 sessions excluded). |
| `tank_randomization_decode.csv` | Per-session recording file name (which encodes strain), batch, run, and the fish assigned to each of the 8 tank positions. |
| `P1-BatchSettingsCombined-v5.csv` | Per-session tank polygon geometry (8 tanks × 4 corners × x/y) used for distortion correction; used to recover the physical stand layout. |

Everything under `data/merged/` and `data/features/` is derived and regenerated by
`src/01_ingest.py` and `src/02_features.py`.

## Tracking file column dictionary

| Column | Description |
|--------|-------------|
| `run` | Batch number (1–13). |
| `dayafternoon` | Encodes `run_within_batch × 10 + physical_tank_position` (e.g. `13` → session 1, tank 3). Sessions 1/3/5 are morning (~11:00), 2/4/6 afternoon (~14:30). |
| `tank` | Fish number within batch (1–8). |
| `fishid` | Global fish identifier = `batch × 10 + fish_within_batch`. |
| `framenumber` | Video frame index. `0` = sentinel row (no data); `1805` = first analyzed frame (first 60 s excluded because the experimenter is in frame); sampling step = 5 frames (~6 Hz at 29.97 fps). |
| `x`, `y` | Distortion-corrected, scaled position. `y = 0` at the tank floor, increasing upward. Empty/`NaN` = no detection in that frame. |
| `deltax`, `deltay` | Signed frame-to-frame displacement (not used by this pipeline). |

## Conventions and notes

- **Vertical orientation:** `y = 0` is the tank floor and increases toward the water
  surface — inverted relative to raw-video pixel coordinates. The top/bottom
  threshold is a fixed `y = 61` after distortion correction.
- **Missing data:** the tracker is frame-differencing, so a `NaN` means the fish did
  not move between samples; freezing and tracking failure cannot be distinguished
  from the coordinates alone. Overall detection rate is ≈64%.
- **Frame range:** samples run from frame 1805 to 54600; the analysis window is
  frames 1805–37805 (~minutes 1–21).
- **No QC exclusions are applied in the tracking file.** Its 624 sessions include all
  recordings; the pipeline removes the 35 flagged sessions (empty tank, sick fish,
  missing video, catastrophically low detection).
- **Sex** was not recorded for individual fish and cannot be recovered.
- **Strain is batch-pure** (each batch is a single strain: 5G inbred or AB wild
  type), so strain is fully confounded with batch.
- The original videos are not included, and several batches' source videos were
  not recovered, so this coordinate stream is the most upstream form of the data
  available.
